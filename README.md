# Модульные Шахматы

Современное веб-приложение для игры в шахматы, созданное с использованием чистого JavaScript, HTML и CSS.

![Main Interface](https://via.placeholder.com/800x450?text=Modular+Chess+Interface) *<!-- Placeholder for actual screenshot if available -->*

## Особенности

- 🎮 **Два режима игры**: Играйте против другого игрока локально или испытайте свои силы против встроенного ИИ.
- 🤖 **Умный ИИ**: Три уровня сложности (Легкий, Средний, Сложный), подходящие как для новичков, так и для опытных игроков.
- ⏱️ **Гибкий контроль времени**:
  - Блиц (3+2)
  - Рапид (5 мин, 10 мин)
  - Классика (30 мин)
  - Пользовательские настройки времени и инкремента.
- 🎨 **Кастомизация**: Четыре цветовые темы оформления доски (Классическая, Дерево, Океан, Темная).
- 📊 **Информативная панель**:
  - Отображение съеденных фигур.
  - Автоматический расчет материального преимущества.
  - Полная история ходов.
- 📱 **Адаптивный дизайн**: Удобная игра на различных устройствах.

## Технологии

- **HTML5 & CSS3**: Семантическая верстка и современный дизайн (Flexbox, Grid).
- **Vanilla JavaScript**: Логика игры, ИИ и управление интерфейсом реализованы без использования внешних библиотек.

## Как запустить

1. Клонируйте репозиторий:
   ```bash
   git clone git@github.com:AlexanderStarchenko/my-first-ssh-project.git
   ```
