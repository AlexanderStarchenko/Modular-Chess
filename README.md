# ♟️ Модульные Шахматы (Modular Chess)

Современное веб-приложение для игры в шахматы, созданное с использованием чистого JavaScript, HTML и CSS. Проект отличается высокой модульностью, продвинутым ИИ и стильным интерфейсом.

![Chess Interface](https://via.placeholder.com/800x450?text=Modular+Chess+Interface)

## 🚀 Особенности

- 🎮 **Два режима игры**: Локальная игра (Pass & Play) и игра против продвинутого ИИ.
- 🤖 **Продвинутый ИИ**:
  - **Easy/Medium**: Основаны на алгоритме Minimax с Alpha-Beta отсечением.
  - **Hard**: Включает в себя Piece-Square Tables (PST) для позиционной оценки, Move Ordering для оптимизации поиска и Quiescence Search для предотвращения "эффекта горизонта".
  - **Stockfish**: Интеграция мощного движка Stockfish 18 (WASM) для анализа и игры на высшем уровне.
- ⏱️ **Гибкий контроль времени**:
  - Пресеты: Блиц (3+2), Рапид (5/10 мин), Классика (30 мин).
  - Кастомный режим с настройкой времени и инкремента.
- 🎨 **Кастомизация**: 
  - 4 темы оформления доски (Classic, Wood, Ocean, Dark).
  - Анимированные переходы и современные эффекты.
- 📊 **Аналитика и UI**:
  - Отображение съеденных фигур и расчет материального преимущества.
  - Интерактивная история ходов.
  - Адаптивная верстка для мобильных устройств.

## 🛠️ Архитектура

Проект построен на модульной структуре для легкости расширения:
- `logic.js`: Ядро шахматной логики и правил.
- `ui.js`: Управление интерфейсом и взаимодействием с пользователем.
- `ai_*.js`: Различные реализации искусственного интеллекта.
- `network.js` & `server.js`: Основа для будущей сетевой игры (Express + Socket.io).

## 💻 Технологии

- **Frontend**: Vanilla JavaScript, HTML5, CSS3.
- **Backend**: Node.js, Express, Socket.io (подготовка к онлайн-режиму).
- **AI Engine**: Stockfish 18 (WebAssembly).

## 📦 Установка и запуск

1. **Клонирование**:
   ```bash
   git clone git@github.com:AlexanderStarchenko/my-first-ssh-project.git
   ```
2. **Запуск**:
   - Просто откройте `index.html` в браузере для одиночной игры.
   - Или запустите локальный сервер:
     ```bash
     npm install
     npm start
     ```
