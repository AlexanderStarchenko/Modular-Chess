# ♟️ Модульные Шахматы (Modular Chess) — Desktop Edition

Современное настольное приложение для игры в шахматы, построенное на базе Electron. Проект сочетает в себе мощь профессиональных движков (Stockfish) и гибкость веб-технологий.

![Chess Interface](https://via.placeholder.com/800x450?text=Modular+Chess+Desktop)

## 🚀 Особенности

- 💻 **Desktop Native**: Полноценное Windows-приложение в одном портативном файле (Portable EXE).
- 🤖 **Продвинутый ИИ**:
  - **Easy/Medium/Hard**: Собственные JS-реализации с использованием Minimax, PST и Quiescence Search.
  - **Extra Hard**: Максимальная мощность с использованием Iterative Deepening и History Heuristic (3.5 сек на ход).
  - **Stockfish Integration**: Анализ и игра на высшем уровне с использованием Stockfish 18 (WASM).
- 📊 **Глубокая Аналитика**:
  - Расчет **точности игры** (Accuracy %) для каждого хода и всей партии.
  - Автоматическая классификация ходов: !! (Блестящий), ! (Хороший), ?! (Неточность), ? (Ошибка), ?? (Зевок).
- ⏱️ **Гибкий контроль времени**:
  - Пресеты: Блиц (3+2), Рапид (5/10 мин), Классика (30 мин).
  - Кастомный режим с настройкой времени и инкремента.
- 🎨 **Кастомизация**:
  - 3 темы оформления доски (Classic, Ocean, Dark).
  - Современный интерфейс с использованием шрифта Outfit и эффектов Glassmorphism.
- ✨ **Плавность и Стабильность (v1.5)**:
  - **Hardened Engine**: Исправлены критические ошибки в симуляции ходов ИИ (взятие на проходе, рокировки, превращения).
  - **100% Тестовое покрытие ИИ**: Все уровни сложности (`Easy`, `Medium`, `Hard`) теперь полностью покрыты тестами.
  - **Анимации ходов**: Плавное перемещение фигур.
  - **Звуковое сопровождение**: Динамические звуки (Web Audio API).
- 📊 **Производительность**: Вычисления ИИ полностью вынесены в Web Workers.

## 🛠️ Архитектура

Проект переведен на **Electron** для обеспечения нативного десктопного опыта:

- `main.js`: Управление жизненным циклом приложения и окнами Electron.
- `ai_worker.js`: Фоновые вычисления для всех уровней сложности ИИ.
- `analysis_manager.js`: Интеграция со Stockfish для послематчевого анализа.
- `logic.js`: Ядро шахматных правил и валидация ходов.

## 💻 Технологии

- **Core**: JavaScript (ES6+), HTML5, CSS3.
- **Frameworks**: Electron, Electron-Builder.
- **AI Engine**: Stockfish 18 (WebAssembly).
- **Communication**: Socket.io (поддержка мультиплеера).

## 📦 Установка и запуск

### 1. Клонирование и установка

```bash
git clone git@github.com:AlexanderStarchenko/my-first-ssh-project.git
npm install
```

### 2. Запуск в режиме разработки

```bash
npm start
```

### 3. Сборка в один .exe файл

```bash
npm run dist
```

Готовый файл появится в директории `release/`.
